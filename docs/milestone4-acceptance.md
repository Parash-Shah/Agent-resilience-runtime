# Milestone 4 acceptance evidence

AgentResilience v1.0 separates repeatable repository evidence from account-specific AWS evidence. CI proves code and infrastructure contracts; `scripts/verify_milestone4.py` produces the live AWS report only after an authenticated deployment.

| Acceptance condition | Repeatable proof |
|---|---|
| Worker killed after step 3 resumes from step 4 | LocalStack test starts and terminates a real worker subprocess inside `dependency_health`; the deployed verifier stops the active ECS task and records the replacement task ID. |
| Redelivery does not repeat a completed side effect | DynamoDB idempotency integration test calls the same restart action twice and observes one backend call; the deployed verifier requires exactly one `restart_service` completion. |
| Transient AWS/model failures retry | Retry classification unit tests plus fault-injected evaluation cases. Post-restart ECS/metric convergence is explicitly retryable. |
| Repeated failures reach the DLQ | LocalStack repeated-outage test verifies DLQ state and audited checkpoint replay. |
| Production remediation requires approval | API/runtime tests prove the restart pauses and unauthenticated approval returns 401. |
| Blocked tools never reach AWS | Policy/tool gateway tests use a backend that fails if a blocked operation is invoked. |
| Dashboard reports reliability signals | API tests cover summary data; Terraform provisions CloudWatch panels for success, retries, DLQ, latency, tool failures, loops, ECS, ALB, and checkout evidence. |
| Live Agents SDK report | `evals/run_local.py --live` exercises the real typed Agents SDK path and writes ignored `evals/results/latest-live.json`. |

## Required final commands

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe evals/run_local.py
.venv\Scripts\python.exe evals/run_local.py --live --limit 1
```

With LocalStack environment variables configured:

```powershell
.venv\Scripts\python.exe -m pytest -q -m integration
```

After AWS deployment with the chaos pause enabled:

```powershell
.venv\Scripts\python.exe scripts/verify_milestone4.py `
  --api-url <terraform-api-url> `
  --cluster <terraform-cluster> `
  --worker-service <terraform-worker-service>
```

Do not claim the last command passed unless `evidence/milestone4/latest.json` was generated by that live run.
